This post is designed to test the `normalizeTagForSlug` function and the overall tag handling system with various special characters and edge cases.

We expect the following transformations for the slugs:

*   `C++` should become `c` (or `cpp` if you prefer to map it, current logic makes it `c`)
*   `React & Redux` should become `react-redux`
*   `café` should become `cafe`
*   `Node.js` should become `node.js`
*   `  leading & trailing spaces  ` should become `leading-trailing-spaces`
*   `multi---hyphens` should become `multi-hyphens`
*   `_underscores_test_` should become `underscores_test_` (or `underscores-test` if you modify `normalizeTagForSlug` to replace underscores)

The display names on the post page and on the `/tags` page should retain their original casing and characters.
