## The Evolution of JavaScript {#evolution-js}
JavaScript has come a long way since its inception. ECMAScript 2015 (ES6) marked a significant milestone, introducing a host of features that make writing JavaScript more intuitive, powerful, and enjoyable. Subsequent versions have continued to refine and expand the language. This article, the first in our "Modern JavaScript Essentials" series, explores key ES6+ features.

## Arrow Functions {#arrow-functions}
Arrow functions provide a concise syntax for writing function expressions. They also lexically bind the `this` value, which can simplify working with `this` in many contexts.

\`\`\`javascript
// Traditional function expression
const addOld = function(a, b) {
  return a + b;
};

// Arrow function
const addNew = (a, b) => a + b;

// Arrow function with 'this'
function Person(name) {
  this.name = name;
  this.greetLater = function() {
    setTimeout(() => {
      console.log(\`Hello, my name is ${this.name}\`); // 'this' correctly refers to Person instance
    }, 100);
  };
}
const person = new Person("Byteskill");
person.greetLater(); // Output after 100ms: Hello, my name is Byteskill
\`\`\`

## `let` and `const` {#let-const}
ES6 introduced `let` and `const` for variable declarations, offering block scope, which is more intuitive than `var`'s function scope.
*   `let`: Declares a block-scoped variable that can be reassigned.
*   `const`: Declares a block-scoped variable that cannot be reassigned (though its properties can be mutated if it's an object or array).

\`\`\`javascript
if (true) {
  let blockScopedVar = "I'm block-scoped!";
  const blockScopedConst = "Me too, and I can't be reassigned.";
  // console.log(blockScopedVar); // Works
}
// console.log(blockScopedVar); // ReferenceError: blockScopedVar is not defined
\`\`\`

## Template Literals {#template-literals}
Template literals provide an easy way to create multi-line strings and perform string interpolation.

\`\`\`javascript
const name = "Byteskill";
const greeting = \`Hello, ${name}!
This is a multi-line string.
1 + 1 = ${1 + 1}\`;
console.log(greeting);
\`\`\`

## Destructuring Assignment {#destructuring}
Destructuring allows you to unpack values from arrays or properties from objects into distinct variables.

\`\`\`javascript
// Object destructuring
const user = { id: 1, username: "byteskiller", email: "dev@byteskill.com" };
const { username, email } = user;
console.log(username); // byteskiller

// Array destructuring
const [first, second] = [10, 20, 30];
console.log(first); // 10
console.log(second); // 20
\`\`\`

## Default Parameters {#default-params}
Functions can now have default values for parameters if no value or `undefined` is passed.

\`\`\`javascript
function greet(name = "Guest") {
  console.log(\`Hello, ${name}!\`);
}
greet("Byteskill"); // Hello, Byteskill!
greet();          // Hello, Guest!
\`\`\`

## Rest & Spread Operators (`...`) {#rest-spread}
*   **Rest Parameter:** Collects all remaining arguments into an array.
*   **Spread Operator:** Expands an iterable (like an array or string) into individual elements.

\`\`\`javascript
// Rest parameter
function sum(...numbers) {
  return numbers.reduce((acc, current) => acc + current, 0);
}
console.log(sum(1, 2, 3, 4)); // 10

// Spread operator
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];
console.log(arr2); // [1, 2, 3, 4]

const obj1 = { a: 1, b: 2 };
const obj2 = { ...obj1, c: 3 };
console.log(obj2); // { a: 1, b: 2, c: 3 }
\`\`\`

## Modules (import/export) {#modules}
ES6 introduced a standardized module system, allowing you to organize code into reusable pieces.

\`\`\`javascript
// lib.js
export const PI = 3.14159;
export function double(n) {
  return n * 2;
}

// main.js
// import { PI, double } from './lib.js'; // In a browser/Node.js environment with ES module support
// console.log(PI);
// console.log(double(5));
\`\`\`
<Callout iconName="Info" variant="info" title="Module Usage">
The exact syntax and setup for ES modules can vary slightly depending on whether you're in a browser environment (using `<script type="module">`) or Node.js (using `.mjs` files or `"type": "module"` in `package.json`).
</Callout>
