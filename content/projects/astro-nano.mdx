## Lightweight {#lightweight-section}

No frameworks or added bulk. Astro Nano is designed to be as lean as possible, ensuring fast load times and a smooth user experience. We've focused on core web technologies and optimized every asset.

## Fast {#fast-section}

Rendered in ~40ms on localhost. Performance is a key feature. By leveraging Astro's static site generation capabilities and minimal JavaScript, pages are served incredibly quickly.

## Configuration {#configuration-section}

The blog posts on the demo serve as the documentation and configuration guide. You'll find detailed instructions on how to customize the theme, set up your content, and integrate various features.
