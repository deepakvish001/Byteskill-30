## Core Idea {#core-idea}
Understanding how pathfinding algorithms explore a search space can be challenging from theory alone. This visualizer brings algorithms like A* to life, showing step-by-step how they make decisions to find the optimal route.

## Algorithms Implemented {#algorithms}
*   **A\* Search:** An informed search algorithm that uses heuristics to guide its search towards the goal more efficiently.
*   **Dijkstra's Algorithm:** Finds the shortest path between nodes in a graph, works well for weighted graphs.
*   **Breadth-First Search (BFS):** An uninformed search algorithm that explores neighbor nodes first before moving to the next level neighbors. Guarantees the shortest path in unweighted graphs.
*   **Depth-First Search (DFS):** Explores as far as possible along each branch before backtracking. Does not guarantee the shortest path.

*   **Frontend:** React (or Vanilla JavaScript for a simpler version)
*   **Graphics:** HTML5 Canvas or SVG for rendering the grid and animations
*   **Styling:** Tailwind CSS (or plain CSS)
